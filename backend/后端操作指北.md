## 记录一下每个文件应该写什么 ##
** 先前一股脑全写main函数里面去了，太臃肿太丑陋了，花时间优化一下代码结构**
backend/
└── app/
    ├── __init__.py
    ├── main.py                # 程序入口
    ├── schemas/               # Pydantic 模型
    │   ├── __init__.py
    │   └── chat.py            # 存放 ChatRequest 等类
    ├── db/                    # 模拟数据库 (存放全局变量)
    │   ├── __init__.py
    │   └── memory.py          # 存放 session_memory, task_db 等
    ├── core/                  # 核心配置与底层模型
    │   └── nlp/
    │       ├── __init__.py
    │       ├── models.py      # 加载 ConvLab 模型 & Monkey Patch
    │       └── session.py     # Session 初始化与管理
    ├── services/              # 业务逻辑
    │   ├── __init__.py
    │   └── chat.py            # 核心对话逻辑 (NLU, DST, Policy, NLG)
    └── routers/               # 接口路由
        ├── __init__.py
        ├── chat.py            # /chat 相关接口
        └── expert.py          # /expert 相关接口
### main.py ###
入口函数，初始化APP，配置一些中间件，挂载路由，启动APP
